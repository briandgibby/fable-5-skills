# Evaluations

This folder will hold A/B/C harness test plans, run artifacts, and review rubrics.

Initial modes:

- Control: no harness.
- Always-on: compact harness loaded from the start.
- Situational: routing triggers deeper modules only when needed.

Start here:

- `candidate-simple-projects.md` lists small projects suitable for testing.
- `initial-ab-test-plan.md` defines the first recommended test.
- `rubric.md` defines scoring.
- `runs/` holds isolated run artifacts.
