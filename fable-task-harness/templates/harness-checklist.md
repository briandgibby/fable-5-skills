# Harness Checklist

Use this as a compact preflight for nontrivial tasks.

- [ ] Requested outcome is understood.
- [ ] Context sufficiency checked.
- [ ] Recoverable context inspected.
- [ ] Source of truth chosen.
- [ ] Relevant skill or reference loaded.
- [ ] Output surface chosen.
- [ ] Tool needs and side effects classified.
- [ ] Exact paths, IDs, schemas, or parameters discovered.
- [ ] Runtime state that must carry forward is captured.
- [ ] Verification path is known.
- [ ] Final result will be accessible to the user.
