# Runtime Preflight Checklist

Use this before API, dynamic tool, dev-server, browser, file, media, or UI/rendering work.

- [ ] Runtime and package manager identified.
- [ ] Writable and read-only paths known.
- [ ] Source inputs and generated outputs separated.
- [ ] Dynamic tool schemas discovered.
- [ ] Exact paths, IDs, selectors, or parameters verified.
- [ ] Required state captured for follow-up calls.
- [ ] Structured outputs have validation criteria.
- [ ] Media or file types handled with appropriate parsers.
- [ ] UI/rendering constraints inspected when relevant.
- [ ] Mutation risks and approval needs checked.
- [ ] Verification command or inspection path chosen.
